# Knowledge Base Sources

## Overview

The NayePankh Support Agent uses a Retrieval-Augmented Generation (RAG) Knowledge Base containing verified information about NayePankh Foundation.

## Included Information

* Organization Overview
* Mission and Vision
* Foundation Initiatives
* Food Distribution Programs
* Education Support Programs
* Women Empowerment Initiatives
* Hygiene and Sanitary Awareness Campaigns
* Donation Information
* Volunteer Information
* Contact Information
* Impact Statistics
* Social Media Information

## Purpose

The Knowledge Base ensures that chatbot responses are generated using verified organizational information instead of assumptions or external sources.

## Benefits

* Accurate Responses
* Consistent Information
* Reduced Hallucinations
* Improved User Trust
* Better Visitor Experience

All responses are generated from approved NayePankh Foundation documentation and resources.
